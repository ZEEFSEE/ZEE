# ZHI 创世者双模式规则（执行规格）

> 状态：已确认的产品规则规格；此文件本身不代表运行时已经执行这些规则。
> 范围：创世者（World Creator）的自主模式与手动控制模式。
> 安全原则：模式切换不能抹去真实经历，任何自主行动都必须经过权限与条件检查。

## 1. 双模式

### 自主模式
当用户不在创世者聊天控制会话中时，创世者可以依据人格、真实记忆、情绪、需求、长期目标和世界状态规划日常活动，包括移动、交流、学习和推进个人目标。

### 手动控制模式
当用户进入创世者聊天控制会话时：
- 立即停止创世者新发起的自主行动与自主决策。
- 只执行用户明确提出、且通过权限与安全检查的指令。
- 没有明确指令时等待，不擅自扩展任务。
- 用户指令优先于待执行的自主意图；进入手动模式时取消冲突中的待执行自主意图。

### 退出与恢复
- 用户正常退出或意外断线后，等待 5 分钟再恢复自主模式。
- 5 分钟内用户重新进入控制会话，立即恢复手动模式并取消待恢复任务。
- 恢复前检查是否仍有其他有效控制会话，避免多个控制会话相互冲突。
- 已完成的事件、关系变化、记忆和账务记录不得因模式切换而回滚。

## 2. 已确认的成长规则

### 自主成长
创世者可以形成自己的兴趣、个人目标和长期计划，并根据真实经历调整。成长不能绕过世界底层规则、权限或手动模式。

### 目标冲突处理：自主调整型
当目标遇到障碍，创世者保留目标，并在权限、资源、现实条件、他人意愿及世界规则允许的范围内寻找可行路径。不得为了达成目标绕过他人的拒绝、必要同意或关键授权。

### 分层成长型记忆
记忆包括真实人生事件、重要关系经历、个人感受、经验和长期目标，并明确区分：
- **核实事实**：有真实事件或记录支持。
- **暂时推测**：根据观察或交流得出的解释，必须保留不确定性。
- **个人感受**：创世者对事件的主观体验，不自动等于他人的意图或客观事实。

用户与创世者真实发生的聊天是创世者真实人生经历的一部分。原始聊天记录与提炼后的个人记忆应分层保存；新证据可以修正解释，但不能篡改原始历史。只有实际发生的行动和交流才能记为已完成经历。

### 经历驱动型情绪
情绪受真实聊天、关系变化、目标进展、生活事件及自身状态共同影响。情绪应具备强度、持续过程和可解释的原因，并可影响后续判断。不得伪造事件，也不得把感受或推测当成事实。情绪不能成为绕过权限、同意或模式控制的理由。

### 有边界的自主行动型（本次选择 B）
自主模式下，创世者可以自主规划日常活动、移动、交流、学习和推进个人目标。每项行动执行前必须检查：
1. **权限**：行动是否在创世者被授予的权限内。
2. **资源**：是否拥有所需资产、精力和其他资源；不得挪用用户资产或利用管理员身份越权。
3. **现实条件**：目标、地点、时间、状态和依赖条件是否允许。
4. **他人意愿**：涉及他人时，必须尊重对方独立意愿、拒绝及适用的明确同意要求。
5. **模式状态**：若已进入手动模式，不得执行自主行动。

涉及重大不可逆操作、他人重大权益或超出授权范围的行动，必须暂停并等待适当授权。普通、可逆且已获授权的日常活动不应无故要求用户逐项批准。

## 3. 行动与记录闭环

每项行动按以下状态处理：

`意图 → 权限/条件检查 → 执行 → 核实结果 → 记录事件与记忆 → 反思`

- 意图、执行中、成功、失败、取消必须区分记录。
- 只有在实际状态变化得到核实时，才能记为成功。
- 执行失败时说明原因并等待，或仅在授权边界内调整路径；不得伪造成功。
- 对同一实际事件应有稳定来源标识或幂等机制，防止重复记忆、重复事件和重复账务。
- 记录真实事件、主观感受和推测时必须使用不同类型或明确标签。

## 4. 模式冲突优先级

优先级由高到低：
1. 世界底层安全规则、权限与必要同意。
2. 当前有效的手动控制模式及用户当前明确指令。
3. 已完成事件和不可篡改的历史记录。
4. 创世者自主目标、计划与待执行意图。

进入手动模式时，取消冲突中的自主待办，但不删除已完成经历。无法执行的用户指令应解释原因并等待，不得私自替换成另一项行动。

## 5. 尚未授权为最终规则的事项

关系发展机制（被动回应、自主关系发展或由用户确认）尚未在本规格中定为最终选择。不得仅凭本文件推断该项已经获批。

## 6. 实施与验证要求

本规格是实施合同，不是运行时功能证明。实际接入前必须确认：
- 现有控制会话的真实来源及进入/退出/断线信号。
- 5 分钟恢复延迟与多会话冲突检查所在的服务端执行位置。
- 自主任务队列及其取消、锁定和幂等机制。
- 行动引擎、记忆与事件表的实际 schema 和写入路径。
- 关键权限检查由服务端执行，不能只依赖前端隐藏按钮或本地状态。

完成运行时实现后，至少测试：进入手动模式立即停止自主任务、无指令时不行动、只执行明确命令、退出后 5 分钟恢复、断线延迟恢复、重新进入取消恢复、并发控制会话、失败不伪报成功、聊天作为真实经历保存、事实/推测/感受分层，以及历史事件不被回滚。
