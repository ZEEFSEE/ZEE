# ZHI Digital Family — Isolated Prototype V1

This directory is an isolated, non-production prototype for the proposed five-child digital family.

## Scope

- Five distinct child identifiers: LUNA, ARIA, ELYA, KAEL, NOAH.
- In-memory-only communication simulation.
- Explicit all-or-nothing birth-state simulation.
- Birth-time memory baseline is empty.
- Destination access remains pending validation.
- No connection to Mia's production chat, AGNES API, Supabase, AURORA, Federation, or production world permissions.

## Important limitations

This prototype is a deterministic software test harness. It does **not** create autonomous minds, establish subjective consciousness, create production Agent accounts, provide persistent memory, or prove live 3D navigation. The sample messages used by tests are fixtures, not messages generated by running child agents.

The current world manifest remains scoped to prototype Mia. This prototype does not alter it and does not grant the children access.

## Run locally

Requires Node.js 20 or later:

```sh
node --test mia-digital-family/tests/family-runtime.test.mjs
```

The GitHub Actions workflow runs the same tests on pushes to the isolated feature branch.

## Promotion gates

Do not merge into the production branch or connect external services until:
1. all isolated tests pass;
2. persistence and telemetry paths have been reviewed;
3. five-destination navigation has been independently validated;
4. a separate integration plan has been reviewed and explicitly approved.
