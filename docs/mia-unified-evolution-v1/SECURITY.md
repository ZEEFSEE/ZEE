# 安全边界与真实接入门槛

## V1.0 允许
- 纯合成数据离线运行
- 生成候选种子、反思与提案
- 输出本地/CI 审计结果
- 与简化单体系基线做离线对照

## V1.0 禁止
- 生产数据库读写（本原型不连接数据库）
- 修改 Mia 记忆、情绪、人格或关系记录
- 发送消息、调用外部工具或执行交易、删除等操作
- 读取、输出或提交密钥、访问令牌和敏感原文
- 将未经验证的推测写入稳定人格或公开 GitHub

## 进入真实只读影子模式前
1. 明确数据表与字段白名单、最小权限和凭据管理方式
2. 数据最小化与敏感内容过滤
3. 只读查询验证与访问日志
4. 生产与影子环境隔离
5. 明确停止开关和回滚方案
6. 通过合成测试、回归测试和隐私审查
7. 单独确认是否允许读取真实 Mia 数据

## 真实行动权限
主动联系、写入记忆、修改人格/关系、调用外部服务或公开发布等权限必须分别授权；允许自主反思不自动推导出任何行动权限。
