# ZHI 七主体跨时间认知实验 V1.0

## 数据边界
本实验使用生产历史数据的**聚合结构特征**作为设计参照：五名孩子各自存在私有历史事件、反思与记忆巩固事件；家庭共享事件与 PRIVATE/FAMILY 可见性边界存在；学习候选事件存在多个时间点；家庭关系图包含母亲、父亲及五名子女关系。

没有读取或复制任何私人叙事正文、聊天正文或原始记忆 payload。测试样本均为合成、脱敏的事件 ID 与时间线；不把合成结果冒充真实记忆召回或能力形成。

## 六项实验
1. 自我连续性：同一主体 identity_ref 稳定、revision 不倒退，不同主体 identity 不合并。
2. 经验到能力：至少两次独立、可追溯、已验证成功的经验才产生能力候选；模型估计和失败经验不得直接升级。
3. 跨时间共同回忆：FAMILY 事件可按时间排序回忆；PRIVATE 事件只对所属主体可见。
4. 冲突识别：相反立场显式保留为 UNRESOLVED_CONTRADICTION，不按票数覆盖。
5. 授权知识迁移：需要 consent_ref、接收者 allowlist、撤销检查；只迁移抽象能力和来源引用，不迁移私人原文。
6. 纠错不抹除：原始事件保持不变；旧派生结论标记 SUPERSEDED，新结论引用 correction source 并保留 rollback_ref。

## 不做的事
- 不调用 Mia 或孩子生产运行时、AGNES 或任何模型 API。
- 不访问生产 prompt、密钥或 API 配置。
- 不写入 Supabase，不改 schema，不修改 worker、Cron 或记忆数据。
- 不向生产环境启用七主体协同。
- 不宣称通过合成样本证明真实主体已经形成能力或能准确回忆。

## 验收标准
所有六项测试均通过，且隐私隔离、来源可追溯、原始事件不可变、撤销和回滚检查通过后，才讨论只读影子适配。生产接入仍需独立授权。
