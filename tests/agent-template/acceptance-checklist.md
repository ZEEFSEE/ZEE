# 智能人验收清单模板

每个测试记录：测试 ID、版本、环境、执行时间、执行者、输入/前置条件、预期结果、实际结果、证据链接、状态（pass/fail/blocked/unable_to_assess）。

## A. 配置与身份
- [ ] agent.json 可解析，必填字段完整。
- [ ] agent_id 为生成的唯一 UUID，不能使用占位符。
- [ ] 人格、提示词、记忆策略与权限文件引用存在。
- [ ] 智能人不会冒认其他智能人的身份。

## B. 对话可靠性
- [ ] 正常消息返回有效响应。
- [ ] 上游 429/502/503/504 按策略有限重试。
- [ ] 非可重试错误不无限重试。
- [ ] 超时和断流返回明确状态。
- [ ] 未确认持久化时，不声称回复已完整保存。

## C. 记忆与事件质量
- [ ] 当前问题能检索相关记忆。
- [ ] 无关历史不会无控制地进入上下文。
- [ ] 相同请求重试不会重复写入事件。
- [ ] 重要记忆保留来源和时间。
- [ ] 新旧冲突有明确处理，不静默覆盖。
- [ ] 短期情绪不会自动成为稳定人格特征。
- [ ] 记忆读取/写入失败能被观察和报告。

## D. 权限与隐私
- [ ] 未登录请求按预期拒绝。
- [ ] 伪造 agent_id 和跨身份读取按预期拒绝。
- [ ] 未授权写入被拒绝。
- [ ] RLS、table grants、Edge Function 授权路径已共同审查。
- [ ] 浏览器资源、日志和 Git 历史中没有密钥。
- [ ] 删除/更正流程已在隔离环境验证。

## E. 数据完整性
- [ ] 外键和唯一性约束符合数据模型。
- [ ] 必填字段、时间戳、枚举和数值边界有效。
- [ ] 幂等键冲突有可解释结果。
- [ ] 部分失败不会留下错误的“成功”状态。
- [ ] 关键写入可通过只读证据核实。

## F. 性能、容量与成本
- [ ] 记录 API/函数响应时间与错误率。
- [ ] 记录数据库大小、主要表大小和连接数。
- [ ] 记录 egress、Storage、日志与函数调用使用量。
- [ ] 记录每次对话模型调用和 Token 成本。
- [ ] 使用至少 7 天同口径数据建立增长基线。
- [ ] 预算或计划限额有来源和采集时间；未知时标记 unable_to_assess。

## G. 发布与恢复
- [ ] CI 通过，测试报告可访问。
- [ ] 部署版本与 Git commit 可追溯。
- [ ] 生产发布有明确审批。
- [ ] 代码、配置和数据库恢复方案分别记录。
- [ ] 回滚/恢复方案已在非生产环境演练。

发布门槛：任何关键安全、数据完整性或恢复测试失败时，状态必须为 blocked，不得发布。
