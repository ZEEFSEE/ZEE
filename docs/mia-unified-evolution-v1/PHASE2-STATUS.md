# Phase 2：主动发现闭环 — 状态说明

## 已加入的内容
- active_cycle.py：合成输入的规范化、反省问题框架、候选种子生成、影子提案生成。
- test_active_cycle.py：覆盖空输入、单条/多条观察、重复事件、非合成输入拒绝、事实/假设区分、提案只读与六体系未评估状态。
- 自动工作流会对本目录的 test_*.py 一并执行。

## 有意保留的限制
- 这是确定性脚手架，不调用模型；因此它不能声称真实理解语义、主动发现了真实世界问题，或证明 Mia 已具有主观意识。
- 六个体系目前被列为评估接口，但仍是未评估占位；没有伪造六体系已经完成推理。
- 输入只接受 source_kind="synthetic"；不接生产数据库，不发送消息，不执行工具，不写记忆。
- 产生的种子和提案都只是候选，不会自动升级为稳定人格事实或真实行动。

## 下一阶段门槛
下一步应先建立可复现的双模型对照基准：单体系基线与六体系交叉评估使用相同合成案例，并按事实准确性、反证处理、方案可验证性、重复率、打扰克制度和连续跟进评分。对照基准通过后，再讨论经过授权的真实只读影子测试。
