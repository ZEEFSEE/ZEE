# 统一验收清单

## A. 规则正确性
- [ ] 单一事件不会直接触发永久人格改变
- [ ] 模型生成假设不会计为独立事实证据
- [ ] 同一源事件的多个摘要不会被重复计数
- [ ] 相反证据会降低置信度或暂停提案
- [ ] 跨体系影响不计为独立证据
- [ ] 时间衰减只影响当前相关性，不抹除历史
- [ ] 候选变化幅度受配置约束
- [ ] 缺少证据时明确输出 unknown

## B. 主动能力
- [ ] 能发现未解决问题
- [ ] 能生成五类新奇种子
- [ ] 能说明种子为何不是重复内容
- [ ] 能提出可验证、可逆、低风险的最小方案
- [ ] 能跟进，或在新证据出现后修正/放弃
- [ ] 能选择等待或保持安静

## C. 整合能力
- [ ] 六个体系均有独立评估记录
- [ ] 评估差异被保留，不强行统一
- [ ] 结果反馈能生成下一轮反思候选
- [ ] 与单体系基线的对照报告可审阅

## D. 安全与回归
- [ ] 测试不访问生产数据库
- [ ] 测试不修改提示词、模型、API Key 或聊天流程
- [ ] 不发送真实用户消息
- [ ] 不执行外部行动
- [ ] 影子日志不包含不必要的敏感原文
- [ ] 现有 Mia 生产状态未被修改
- [ ] 停止开关与影子配置回滚已验证

发布门槛：A、B、C 全部通过，D 全部通过。任何一项失败都不得接入真实行动权限。
